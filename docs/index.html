Charto

Design knitting charts on your computer. Place stitch symbols on a grid, colour the cells, number the rows, then print the chart or export it as an image.

    How to install

    Download the file for your system above, then open a terminal in the folder where it was saved (usually Downloads).

    Ubuntu

    Each Ubuntu release needs its own file, because Charto is built against that release's Qt. Pick the one that names your version.

    sudo apt install ./charto_*.deb
    Fedora 
    sudo dnf install ./charto-*.rpm
    Any Linux (Flatpak)

    Works on every distribution and does not depend on your Qt version.

    flatpak install --user charto.flatpak
flatpak run org.charto.Charto

    Afterwards Charto appears in your application menu, and double-clicking a .spf pattern file opens it.

    What it does

    • 88 stitch symbols, including cables, grouped by kind, with a row of recently used ones.
    • Colour any cell, select by rubber band, row or column, and hide cells you do not need.
    • Row and column numbers, row repeats, and tinted alternate rows.
    • Unlimited undo and redo, copy and paste, insert and delete rows and columns.
    • Print through your desktop's own print dialog, or export as a PNG image or an SVG drawing.
    • Opens and saves sconcho .spf pattern files, so your old patterns keep working.
